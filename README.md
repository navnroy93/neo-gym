# NEO GYM — Premium Luxury Fitness & Performance Center

A cinematic, responsive, high-conversion fitness website for **NEO GYM** ("Built by Discipline. Defined by Strength.") featuring:
- 📱 **Mobile-First Responsive Design**: Optimized across mobile (320px–430px), tablets (768px), laptops (1024px–1440px), and large desktops (1600px+) with an editorial luxury aesthetic and Light/Dark theme switcher.
- 💬 **WhatsApp Direct Connect**: Instant popup routing pre-filled messages and inquiries directly to the gym owner desk (+91 8892152766).
- 🤖 **NEO Gym Assistant Bot**: Real-time virtual gym desk answering timings, membership fees, machinery, personal coaching, free trial passes, and nutrition tips.
- 🎬 **Sequential Workout Video Theater**: Auto-advancing video player with custom timeline scrubbing, volume slider, mute, fullscreen, and keyboard shortcuts.
- 🔒 **Owner Video Upload**: Secure video uploads and management protected by Owner Security PIN.
- 📊 **Member Lead Registration**: Captures visitor leads and automatically logs them into the backend Excel sheet (`data/SMN_Gym_Members.xlsx`).
- 🖼️ **Interactive Facility Showcase & Lightbox**: High-resolution gallery with category filters and click-to-enlarge modal.
- 🏋️ **Animated Browser Tab Favicon**: Rep-counting dumbbell curl motion on browser tabs.

---

## 🚀 Quick Start (Local Run)

1. Install dependencies (if not already installed):
   ```bash
   npm install
   ```
2. Start the web server:
   ```bash
   npm start
   ```
3. Open in your browser:
   `http://localhost:3000`

---

## 🌐 Deploying Online (Free Cloud Hosting)

This application runs on Node.js / Express.
1. Connect this repository to [Render](https://render.com), Railway, or Koyeb.
2. Choose **Web Service** -> **Node.js Environment**.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. Deploy and get your live link.
